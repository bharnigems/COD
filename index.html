◈ Firebase Setup
Connect Bharni Gems to Firebase Firestore for real-time sync across all your devices. Takes 5 minutes. Free forever at your scale.
Step 1 — Create a Firebase Project
Go to console.firebase.google.com → Add project → name it "bharni-gems" → disable Google Analytics → Create project.
Step 2 — Create a Firestore Database
In your project → Build → Firestore Database → Create database → Start in test mode → Choose a region (asia-south1 for Mumbai) → Enable.
Step 3 — Get your Web App credentials
Project Settings (gear icon) → Your apps → Add app → Web ( icon) → Register app as "bharni-gems-web" → Copy the firebaseConfig object. It looks like this:
const firebaseConfig = { apiKey: "AIza...", authDomain: "bharni-gems.firebaseapp.com", projectId: "bharni-gems", storageBucket: "bharni-gems.appspot.com", messagingSenderId: "123456789", appId: "1:123:web:abc" };
Step 4 — Paste your credentials below
⚠️ Note on images: Piece photos are large (base64). They are stored locally only and not synced to Firestore to keep documents under the 1MB limit. All other data — orders, vendors, customers, follow-ups, activity log — syncs fully.
